# 产教贯通能力凭证承接

管理贯通培养中的能力证据、学分折算、实习承接与授权查询。

## 领域范围

系统涉及职业院校教务人员、学生、企业实训负责人、能力复核人员。当前领域资料记录以下业务事实：

- 培养路径跨越中职、高职和应用型本科
- 技能形成依赖课程、竞赛、实践和实习的组合证据
- 专业设置与企业岗位需求需要持续对齐

后续实现需要围绕这些边界组织服务：

- 培养路径版本
- 能力证据复核
- 学分折算守恒
- 授权最小披露
- 转段恢复

`contracts/domain.schema.json` 定义领域资料结构，`fixtures/domain.json` 提供不含真实身份信息的示例，`src/skill_pathway_credential/context.py` 负责读取并检查这些资料。

## 开发命令

- 运行测试：`python3 -m unittest discover -s tests -v`
- 编译检查：`python3 -m compileall -q src`

上述命令只读取仓库内资料，不需要连接外部业务服务。
